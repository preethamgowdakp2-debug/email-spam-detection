ABOUT THE PROJECT

How SpamGuard Works

An intelligent email classification system using Machine Learning.

01. Python

Python is used to build the backend and execute the prediction process.

02. TF-IDF Vectorization

Converts message text into numerical features for machine learning.

03. Naive Bayes Classifier

Uses the trained classification model to identify spam and legitimate messages.

04. Flask Framework

Connects the website interface with the Python machine learning model.

Project Objective

To identify unwanted and suspicious messages using machine learning and natural language processing.
